## Explicit limits

Local CLI workflows and x402 signing use the optional CLI adapter. This is not a claim that every command has a native HTTP implementation. Sandbox pause/resume/fork/snapshot/restore remain unsupported by the Kubernetes backend and return 501. Successful custom DNS verification and account-level payment effects require a separate approved live test.

The [coverage map](../tests/contracts/cli-coverage.json) and [migration notes](cli-parity.md) document the mapping and changed return types. A release has not been published as part of this audit.
